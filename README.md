# Shape of Dreams mods

Host-only mods for *Shape of Dreams*, in one repository.

| Folder | What it is |
|---|---|
| [`last-stand/`](last-stand/README.md) | Last Stand: endless waves in one boss arena. |
| [`dream-arena/`](dream-arena/README.md) | Dream Arena: a PvP arena mode. |
| [`modding/`](modding/README.md) | A guide to modding Shape of Dreams, with Last Stand as the worked example. |

Each mod builds, packs and ships on its own. See its `AGENTS.md` for how.
